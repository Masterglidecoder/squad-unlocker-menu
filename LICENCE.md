## 🧩 About

**Squad catalog Menu** is a curated list of Squad open-source tools:

- **Overlays** — on-screen helpers, layout notes, tactical map overlays, and minimap markers
- **Quality-of-Life Helpers** — loadout presets, spawn point notes, and UI customization
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Tactical Helpers
- Unlock All Loadouts — access all kits and roles for single-player study
- Minimap Overlay — customizable markers and map notes
- Spawn Point Notes — record and review spawn locations
- Playback Speed — adjust replay speed for study (0.1x to 5x)

### 🎨 Customization
- Loadout Presets — save and load custom gear configurations
- UI Skin Notes — organize interface themes
- Custom HUD — rearrange on-screen elements for clarity

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Gravity Control Notes — manually adjust movement in the editor
- Tactical Pause — pause and plan without pressure
